# By Jeremy Alexander

Profile and selected-work index for [byjeremyalexander.com](https://byjeremyalexander.com), implemented from the supplied Figma and hand-drawn wireframes.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run build
```

Project links use concise one-word paths. Those destination pages are intentionally blank until their content is added.
